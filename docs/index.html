Installation Instructions

Choose your operating system below for simple installation steps.

Windows Installation (10/11)

  1. Download the installer: Morada-Setup-1.0.0.exe.
  2. Double-click the installer. If Windows SmartScreen appears, click More info and then Run anyway.
  3. Follow the setup wizard to create desktop and start menu shortcuts.

macOS Installation (Apple Silicon & Intel)

  1. Download the disk image: Morada-1.0.0.dmg.
  2. Open the downloaded DMG file and drag Morada into your Applications folder.
  3. If macOS Gatekeeper asks for verification on first open, right-click (or Control-click) Morada in Applications and choose Open.

Linux Installation

  1. AppImage (Any Distro): Download Morada-1.0.0.AppImage, grant execute permission, and launch: chmod +x Morada-1.0.0.AppImage && ./Morada-1.0.0.AppImage
  2. Debian / Ubuntu: Download morada_1.0.0_amd64.deb and install via terminal: sudo dpkg -i morada_1.0.0_amd64.deb
